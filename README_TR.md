# FitPlan Pro Unique PWA v1

iPhone'da Safari üzerinden kullanılmak üzere hazırlanmış PWA prototipidir.

## Ana ekrana ekleme
PWA'yı HTTPS üzerinden yayınladıktan sonra Safari'de açın:
Paylaş -> Ana Ekrana Ekle -> Web Uygulaması Olarak Aç -> Ekle.

## İçerik
- Bugün ekranı
- Kilo/hedef
- Su ve adım demo takibi
- Öğünler ve porsiyonlar
- Saatlik program
- Profil
- localStorage ile cihaz içi kayıt
- Yemek fotoğrafı seçme girişi
- AI koç entegrasyon noktası

Gerçek AI/internet araştırması ve fotoğraf analizi için güvenli bir backend gerekir. API anahtarlarını tarayıcı koduna koymayın.
